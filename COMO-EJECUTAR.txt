Cómo correr el proyecto

Necesitas Node.js instalado.

Primera vez: instalar dependencias

  cd server
  npm install
  cd ..

  cd client
  npm install
  cd ..

Conexión a Oracle (base gestorParqueo)

  1. En la carpeta server, copia .env.example a .env

  2. Edita .env y completa:
     - ORACLE_USER=tu_usuario
     - ORACLE_PASSWORD=tu_password
     - ORACLE_CONNECT_STRING=localhost:PUERTO/SID

  3. Si no usas Oracle aún, el servidor igual arranca; la ruta /api/health indicará si la DB está conectada.

  4. Probar la conexión en Postman (con el servidor levantado):
     GET http://localhost:3001/api/health
     Respuesta esperada: { "ok": true, "oracle": true } si la BD está conectada.

Para ejecutar hay que abrir dos terminales. En una:

  cd server
  npm run dev

En la otra:

  cd client
  npm run dev

Cuando arranquen los dos, abrir en el navegador http://localhost:5173

Para apagar, Ctrl+C en cada terminal.
