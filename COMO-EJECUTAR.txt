Cómo correr el proyecto

Necesitas Node.js instalado (versión 18 o superior).

Este proyecto usa pnpm como gestor de paquetes (ya no npm).

Habilitar pnpm (una sola vez por computadora)

  corepack enable
  corepack prepare pnpm@latest --activate

Primera vez: instalar dependencias

  cd server
  pnpm install
  cd ..

  cd client
  pnpm install
  cd ..

  Nota: la primera vez, pnpm puede avisar que algunas dependencias tienen
  scripts de instalación que quedaron bloqueados (es una medida de seguridad).
  Si ocurre, ejecuta dentro de esa carpeta:

     pnpm approve-builds

  y aprueba al menos "esbuild" (lo necesita Vite para compilar) y "oracledb"
  si aparece en la lista.

Conexión a Oracle (base gestorParqueo)

  1. En la carpeta server, copia .env.example a .env

  2. Edita .env y completa:
     - ORACLE_USER=tu_usuario
     - ORACLE_PASSWORD=tu_password
     - ORACLE_CONNECT_STRING=localhost:PUERTO/SID

  3. Si no usas Oracle aún, el servidor igual arranca; la ruta /api/health indicará si la DB está conectada.

  4. Probar la conexión en Postman (con el servidor levantado):
     GET http://localhost:3001/api/health
     Respuesta esperada: { "ok": true, "oracle": true } si la BD está conectada.

Para ejecutar hay que abrir dos terminales. En una:

  cd server
  pnpm dev

  Si necesitas sembrar catálogos/espacios demo una sola vez:
  pnpm db:seed-catalogo-funcional

En la otra:

  cd client
  pnpm dev

Cuando arranquen los dos, abrir en el navegador http://localhost:5173

Para apagar, Ctrl+C en cada terminal.
